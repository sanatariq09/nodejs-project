# ⭐ **Project Summary**
This API offers a complete authentication and authorization system designed for modern applications.
It handles user registration, login, session management using JWTs, and provides secure access control based on user roles such as **Admin**, **Manager**, and **User**.
Using modular controllers, middlewares, and models, the project maintains a clean structure that is easy to scale and extend.
Whether you're building an admin panel, SaaS dashboard, or enterprise-level backend, this API serves as a solid foundation with built-in security features and high-quality code architecture.

# 📌 **Features**
### 🔐 Authentication System
A secure login and registration flow using JWT tokens to ensure safe session handling.
### 🛡 Role-Based Authorization
Protect sensitive routes with middleware that checks user roles before granting access.
### 🧩 Modular Architecture
Controllers, Models, and Routes are structured cleanly for maintainability and scalability.
### 🌐 RESTful API
All endpoints follow REST standards, making the API simple to integrate with any frontend.
